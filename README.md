# ma-valuation-acquisition-analysis
LSEG–Octus Acquisition Analysis

Project: M&A Transaction Analysis
Transaction: London Stock Exchange Group's proposed acquisition of Octus
Announcement Date: 22 October 2026
Status: Independent research project

1. Project Overview
This project examines London Stock Exchange Group's proposed acquisition of Octus, a provider of credit intelligence, data and workflow solutions.

The objective is to evaluate the transaction from an investment banking perspective, focusing on strategic rationale, valuation, acquisition multiples, financing and expected financial impact.

2. Research Objectives
Understand the strategic rationale behind the acquisition.

Analyse the disclosed transaction consideration and financial metrics.

Calculate indicative enterprise value-to-revenue and enterprise value-to-EBITDA multiples, subject to the availability of relevant data.

Develop an illustrative discounted cash flow valuation using clearly documented assumptions.

Examine comparable companies and relevant valuation benchmarks.

Assess the potential financial benefits, risks and execution considerations.

3. Planned Analysis

Transaction Overview
Review the announced consideration, transaction structure, financing and expected completion timeline.

Financial Analysis
Examine publicly disclosed financial information and identify any limitations in the available data.

Valuation
Develop an illustrative DCF model and assess the acquisition price using relevant valuation multiples.

Strategic Assessment
Evaluate the acquisition's strategic rationale, potential synergies and key execution risks.
